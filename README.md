# AI CareerGuide

AI CareerGuide is a web-based career guidance system
designed for Vietnamese high school students.

## Features
- Career interest assessment using RIASEC
- Personalized university major recommendations
- University search and comparison
- Personalized learning roadmaps
- AI-assisted learning guidance

## Tech Stack
- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Python, FastAPI, Pydantic
- Database: PostgreSQL, SQLAlchemy, Alembic
- Testing: Pytest, Playwright
- DevOps: Docker, GitHub Actions
